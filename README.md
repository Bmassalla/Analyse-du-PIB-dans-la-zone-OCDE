# Analyse du PIB dans la zone OCDE

## Contexte

Le **Produit Intérieur Brut (PIB)** est un indicateur permettant de mesurer la richesse produite par un pays sur une période donnée. Il peut être analysé selon trois approches complémentaires :

* **l’approche par la production** ;
* **l’approche par les revenus** ;
* **l’approche par les dépenses**.

Ce projet s’intéresse plus particulièrement à l’**approche par les dépenses**, qui permet d’analyser les différentes composantes de la demande au sein d’une économie.

## Présentation de l'étude

Notre étude porte sur l’évolution du **Produit Intérieur Brut (PIB) selon l’optique des dépenses dans la zone OCDE**, sur une période de **24 ans, de 1996 à 2019**, et pour **28 pays membres**.

L’approche par les dépenses prend en compte les dépenses réalisées pour l’acquisition de biens et de services produits dans une économie au cours d’une période donnée. Elle comprend notamment :

* les **dépenses de consommation des ménages** ;
* les **dépenses publiques** ;
* les **investissements des entreprises** ;
* le **solde de la balance commerciale**, correspondant aux exportations nettes.

## Problématique

L’objectif de ce travail est d'étudier l’influence des différentes variables explicatives sur le PIB, en tenant compte simultanément de deux dimensions :

* une **dimension individuelle**, correspondant aux différents pays étudiés ;
* une **dimension temporelle**, correspondant à l’évolution des variables entre 1996 et 2019.

La prise en compte de ces deux dimensions conduit naturellement à l’utilisation de **modèles économétriques sur données de panel**.

La problématique centrale de cette étude est donc la suivante :

> **Quel modèle économétrique doit être privilégié afin de réaliser des prévisions du PIB à partir des différentes composantes de l’approche par les dépenses ?**

## Méthodologie

Afin de répondre à cette problématique, l’étude est réalisée à l’aide de plusieurs logiciels et méthodes économétriques.

Le projet est organisé en **trois parties** :

1. **Application avec TSP**
   Une première analyse des données et une modélisation économétrique sont réalisées à l’aide du logiciel TSP.

2. **Application avec Stata**
   Une seconde analyse est menée sous Stata, notamment à travers les différentes méthodes de modélisation adaptées aux données de panel.

3. **Application avec SAS**
   Enfin, une troisième application est réalisée sous SAS afin de compléter l’analyse et de comparer les résultats obtenus avec les différentes approches.

## Objectif du projet

L’objectif final est de **comparer les différentes spécifications économétriques**, d’identifier le modèle le plus adapté aux données étudiées et d’évaluer sa capacité à expliquer et à prévoir l’évolution du PIB dans les pays de l’OCDE étudiés.

Ce projet permet ainsi de mettre en pratique les méthodes d’**économétrie des données de panel** et de comparer leur implémentation dans différents environnements statistiques.
